# FIA-O 🚀

Aplicación web optimizada para el control diario de negocios, permitiendo gestionar de manera ágil los fiados, pagos de clientes, inventario y reportes financieros.

## ✨ Características principales
* 👤 **Control de clientes y saldos:** Visualiza rápidamente deudas y límites de crédito con bloqueo automático opcional.
* 📦 **Inventario integrado:** Búsqueda y gestión de productos por categorías (abarrotes, panadería, bebidas, lácteos).
* 📊 **Reportes y analíticas:** Visualización de flujos de caja y exportación de datos.
* 📍 **Mapa de cobertura:** Ubicaciones y sucursales conectadas.
